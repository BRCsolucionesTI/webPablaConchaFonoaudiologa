Evaluación ADI-R

Apoyo diagnóstico en espectro autista mediante un instrumento clínico reconocido internacionalmente.

Apoyo dentro del proceso diagnóstico

La Entrevista Diagnóstica del Autismo Revisada es un instrumento clínico aplicado a cuidadores para complementar el proceso diagnóstico.

Este instrumento se utiliza dentro del proceso de evaluación para apoyar el abordaje diagnóstico, desde una mirada profesional, integral y respetuosa con cada paciente y su familia.
